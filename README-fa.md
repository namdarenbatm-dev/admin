# پنل ادمین توسن تکنو (PWA)
1. کل پوشه را روی میزبان **HTTPS** آپلود کنید (Vercel / Netlify / Nginx). فایل شروع: index.html
2. اندروید: Chrome ← Install app. آیفون: Safari ← Share ← Add to Home Screen.
3. داده‌ها نمایشی و محلی‌اند (localStorage). در تنظیمات می‌توانید بازنشانی یا پشتیبان JSON بگیرید.
4. با انتشار نسخه جدید، نام V در sw.js را عوض کنید.
